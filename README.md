# Disney Movies

## Назначение проекта

Учебный веб-сайт о фильмах Disney. Проект предназначен для демонстрации навыков создания и оформления веб-страниц.

## Технологии

- HTML
- CSS
- JavaScript
- PHP

## Структура проекта

- index.html — главная страница
- css/ — стили сайта
- js/ — JavaScript-файлы
- images/ — изображения
- 12.php — PHP-файл
- README.md — описание проекта

## Способ запуска

Для просмотра сайта необходимо открыть файл index.html в браузере.

1. Проверка структуры проекта.
2. Проверка кода на ошибки.
3. Автоматическая публикация обновлённой версии сайта.
